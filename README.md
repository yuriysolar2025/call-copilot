# call-copilot

Копилот на созвонах для Claude. Zoom расшифровывает созвон в окне «Мои заметки»,
скилл читает это окно прямо на твоём Mac и даёт Claude живой транскрипт.
Во время разговора Claude следит за ним и подсказывает готовые реплики,
после созвона делает итог.

Без API-ключей, без микрофона, без облачного распознавания. Текст созвона никуда не уходит.

## Что нужно

- Mac (macOS 14 и новее). На Windows не работает: используется системный OCR Apple.
- Zoom с включёнными «Мои заметки» (функция Zoom, организатор должен разрешить заметки участникам).
- Claude Code или приложение Claude с поддержкой скиллов и доступом к терминалу.
- Один раз: Command Line Tools Apple (`xcode-select --install`, бесплатно) и разрешение «Запись экрана».

## Установка за 10 минут

1. Скачай репозиторий в папку скиллов:
   ```bash
   git clone https://github.com/yuriysolar2025/call-copilot.git ~/.claude/skills/call-copilot
   ```
   (или кнопка Code → Download ZIP и распаковать в `~/.claude/skills/call-copilot`).
2. Напиши Claude: **«поставь копилот»**. Он запустит `scripts/install.sh` и проведёт по шагам.
3. Выдай разрешение «Запись экрана» программе `zoomnotes-ocr` и `python3`, когда Claude попросит.
4. Открой Zoom, включи «Мои заметки», подожди 10 секунд. Claude проверит, что текст пошёл.

## Как пользоваться

- В начале созвона: «подключись к созвону». Claude подтверждает, что видит текст, и дальше молчит, пока нечего сказать.
- По ходу: «как мне ответить», «что он сказал про цену», «подскажи, что сказать».
- В конце: «отключись», и Claude даёт итог: решения, обещания, следующие шаги.

Перед первым созвоном заполни `persona.md` (кто ты, что продаёшь, как говоришь, цены)
и `checklist.md`. Подсказки станут твоим голосом, а не общими словами.

## Что внутри

| Файл | Зачем |
|---|---|
| `SKILL.md` | инструкция для Claude: установка, слежение, как подсказывать |
| `scripts/ocr.swift` | снимок окна Zoom и распознавание текста (Apple Vision) |
| `scripts/zoom_notes_live.py` | фоновый цикл: склеивает снимки в `live.txt` |
| `scripts/follow.py` | печатает только новые строки транскрипта, будит Claude |
| `scripts/install.sh`, `scripts/uninstall.sh` | поставить и снять |
| `hints.md` | образцы глубины подсказок |
| `persona.md`, `checklist.md` | твой голос и что нельзя забыть |

Данные: `~/Library/Application Support/CallCopilot/` (live.txt, live.json, archive/).
Лог: `~/Library/Logs/call-copilot.err`.

## Ограничения этой версии

Только Zoom и только «Мои заметки»: читается то, что Zoom успел распознать.
Google Meet, телефон, разговоры вживую и запись своего голоса требуют распознавания речи
на устройстве. Это расширенная версия с микрофоном, она отдельно.
